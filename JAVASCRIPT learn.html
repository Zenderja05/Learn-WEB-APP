JavaScript

JavaScript คืออะไร

คือ ภาษาคอมพิวเตอร์สำหรับพัฒนาเว็บไซต์ ใช้ควบคุมการทำงานและความโต้ตอบ (Interactive) บนหน้าเว็บ ทำให้เว็บไซต์ไม่เป็นเพียงหน้าแสดงข้อมูลแบบนิ่ง

การคอมเมนท์

ใช้สำหรับเขียนคำอธิบายโค้ด เพื่อให้ผู้อ่านเข้าใจโค้ดได้ง่ายขึ้น โดยจะไม่ถูกประมวลผล

  • คอมเมนท์แบบบรรทัดเดียว ใช้เครื่องหมาย //
  • คอมเมนท์แบบหลายบรรทัด ใช้เครื่องหมาย /* */
  • หรือคีย์ลัด Ctrl+/ สำหรับคอมเมนท์/เลิกคอมเมนท์

การดูรันโค้ด JavaScript

สามารถดูผลลัพธ์ของโค้ด JavaScript ได้โดยใช้ Developer Tools ในเว็บเบราว์เซอร์

  • กด F12 หรือคลิกขวาแล้วเลือก "ตรวจสอบ" (Inspect)
  • ไปที่แท็บ "Console"
  • พิมพ์โค้ด JavaScript ลงในคอนโซลแล้วกด Enter เพื่อรันโค้ด

วิธีการเพิ่ม JavaScript ใน HTML

สามารถเพิ่มโค้ด JavaScript ลงในไฟล์ HTML ได้ 3 วิธี ดังนี้

  • แบบฝัง (Inline): ใช้ attribute "onclick", "onload" เป็นต้น ภายในแท็ก HTML
  • แบบภายใน (Internal): ใช้แท็ก <script> ภายในไฟล์ HTML
  • แบบภายนอก (External): ใช้แท็ก script src="ไฟล์.js"</script> เพื่อเชื่อมโยงไปยังไฟล์ .js ภายนอก

ตัวแปรเก็บข้อมูล

ใช้สำหรับเก็บข้อมูลที่ต้องการใช้งานในโปรแกรม JavaScript โดยสามารถประกาศตัวแปรได้ด้วยคำสั่งดังนี้

  • var: ประกาศตัวแปรแบบทั่วไป
  • let: ประกาศตัวแปรที่มีขอบเขตภายในบล็อก (block scope)
  • const: ประกาศค่าคงที่ที่ไม่สามารถเปลี่ยนแปลงค่าได้

การทำ input/output

JavaScript มีวิธีการรับข้อมูลจากผู้ใช้และแสดงผลลัพธ์ดังนี้

    Input(รับข้อมูล)

  • prompt(): ใช้สำหรับรับข้อมูลจากผู้ใช้ผ่านกล่องโต้ตอบ 
    let name = prompt("Enter your name:");

    • Output(แสดงผลลัพธ์)

  • alert(): ใช้สำหรับแสดงกล่องข้อความ
  • console.log(): ใช้สำหรับแสดงผลในคอนโซล

ประเภทข้อมูล (Data Types)

JavaScript มีประเภทข้อมูลหลักๆ ดังนี้

  • Number: ตัวเลขทั้งจำนวนเต็มและทศนิยม

    • let Num = 10;

  • String: ข้อความที่อยู่ในเครื่องหมายคำพูดเดี่ยว (' ') หรือคำพูดคู่ (" ")

    • let Str = "Hello JavaScript";

  • Boolean: ค่าความจริง มีค่าได้เพียง true หรือ false

    • let Bool = true;

  • Array: กลุ่มของข้อมูลที่จัดเก็บในรูปแบบลำดับ

    • let Arr = [1, 2, 3, 4, 5];

  • Object: โครงสร้างข้อมูลที่เก็บค่าคู่ของคีย์และค่า

    • let Obj = {name: "John", age: 30};

  • null: ค่าที่แสดงถึงการไม่มีค่า
  • undefined: ค่าที่แสดงถึงตัวแปรที่ยังไม่ได้กำหนดค่า

ข้อมูลประเภท String

String คือ ข้อความที่อยู่ในเครื่องหมายคำพูดเดี่ยว (' ') หรือคำพูดคู่ (" ")

  • การเชื่อมต่อข้อความ (Concatenation): ใช้เครื่องหมาย + เพื่อเชื่อมข้อความหลายๆ ส่วนเข้าด้วยกัน

    • let greeting = "Hello, " + "world!";

  • การหาความยาวของข้อความ: ใช้ property length เพื่อหาจำนวนตัวอักษรในข้อความ

    • let length = greeting.length;

  • การเข้าถึงตัวอักษร: ใช้ดัชนี (index) เพื่อเข้าถึงตัวอักษรในข้อความ โดยเริ่มต้นที่ 0

    • let firstChar = greeting[0];

ข้อมูลประเภท Number

Number คือ ตัวเลขทั้งจำนวนเต็มและทศนิยม

  • การบวก (+), การลบ (-), การคูณ (*), การหาร (/), การหารแบบเศษส่วน (%), การยกกำลัง (**)

    • let sum = 5 + 3;

  • การเพิ่มค่าตัวแปร (Increment): ใช้เครื่องหมาย ++ เพื่อเพิ่มค่าตัวแปรทีละ 1

    • let count = 0; count++;

  • การลดค่าตัวแปร (Decrement): ใช้เครื่องหมาย -- เพื่อ ลดค่าตัวแปรทีละ 1

    • let count = 5; count--;

  • NaN (Not a Number): ค่าที่เกิดขึ้นเมื่อการคำนวณไม่สามารถทำได้ เช่น 0/0
  • Infinity: ค่าที่เกิดขึ้นเมื่อการคำนวณมีค่ามากเกินไป เช่น 1/0

ข้อมูลประเภท Boolean

Boolean คือ ค่าความจริง มีค่าได้เพียง true หรือ false

  • ใช้ในการเปรียบเทียบค่าต่างๆ เช่น เท่ากับ (==), ไม่เท่ากับ (!=), มากกว่า (>), น้อยกว่า (<), มากกว่าหรือเท่ากับ (>=), น้อยกว่าหรือเท่ากับ (<=)

    • let isAdult = age >= 18;

  • ใช้ในการเชื่อมโยงเงื่อนไข เช่น และ (&&), หรือ (||), ไม่ (!)

    • let canVote = isCitizen && isAdult;

ประเภทข้อมูล array

Array คือ กลุ่มของข้อมูลที่จัดเก็บในรูปแบบลำดับ

  • การประกาศ Array: ใช้เครื่องหมาย [ ] เพื่อประกาศ Array

    • let fruits = ["Apple", "Banana", "Cherry"];

  • การเข้าถึงข้อมูล: ใช้ดัชนี (index) เพื่อเข้าถึงข้อมูลใน Array โดยเริ่มต้นที่ 0

    • let firstFruit = fruits[0];

  • การเพิ่มข้อมูล: ใช้เมธอด push() เพื่อเพิ่มข้อมูลลงใน Array

    • fruits.push("Orange");

  • การลบข้อมูล: ใช้เมธอด pop() เพื่อลบข้อมูลตัวสุดท้ายออกจาก Array

    • fruits.pop();

  • การลบข้อมูลตัวแรก: ใช้เมธอด shift() เพื่อลบข้อมูลตัวแรกออกจาก Array

    • fruits.shift();

  • การเพิ่มข้อมูลตัวแรก: ใช้เมธอด unshift() เพื่อเพิ่มข้อมูลที่จุดเริ่มต้นของ Array

    • fruits.unshift("Mango");

  • การเรียงข้อมูล: ใช้เมธอด sort() เพื่อเรียงข้อมูลใน Array

    • fruits.sort();

  • ความยาวของ Array: ใช้ property length เพื่อหาจำนวนข้อมูลใน Array

    • let length = fruits.length;

  • ข้อมูลมากกว่าสองมิติ: สามารถใช้ Array ซ้อนกันเพื่อจัดเก็บข้อมูลในรูปแบบสองมิติหรือมากกว่า

    • let matrix = [[1, 2], [3, 4]];

ประเภทข้อมูล object

Object คือ โครงสร้างข้อมูลที่เก็บค่าคู่ของคีย์และค่า

  • การประกาศ Object: ใช้เครื่องหมาย { } เพื่อประกาศ Object

    • let person = {name: "Alice", age: 25, city: "Bangkok"};

  • การเข้าถึงค่า: ใช้จุด (.) หรือตัวหนอน ([]) เพื่อเข้าถึงค่าของคีย์ใน Object

    • let name = person.name; // หรือ let name = person["name"];

  • การเพิ่มหรือแก้ไขค่า: สามารถเพิ่มหรือแก้ไขค่าของคีย์ใน Object ได้โดยตรง

    • person.age = 26; person.country = "Thailand";

  • การลบค่า: ใช้คำสั่ง delete เพื่อลบคีย์และค่าจาก Object

    • delete person.city;

  • การวนลูปผ่าน Object: ใช้คำสั่ง for...in เพื่อวนลูปผ่านคีย์ใน Object
    •             for (let key in person) {
                console.log(key + ": " + person[key]);
            }
  • Array of Object: สามารถเก็บข้อมูลในรูปแบบ Object ซ้อนกันได้

    • let users = [{name: "Alice", age: 25}, {name: "Bob", age: 30}];

  • การเข้าถึงข้อมูลใน Array of Object: ใช้ดัชนี (index) และชื่อ property เพื่อเข้าถึงข้อมูลใน Array of Object 
    •             let users = [{name: "Alice", age: 25}, {name: "Bob", age: 30}];

            let firstUser = users[0]; // เข้าถึง Object แรกใน Array
            console.log(firstUser.name); // Output: Alice
  • การเก็บข้อมูลในรูปแบบ Object ซ้อนกันได้
    •             let company = {
                name: "Tech Corp",
                address: {
                    street: "123 Main St",
                    city: "Bangkok",
                    country: "Thailand"
                },
                employees: [
                    {name: "Alice", position: "Developer"},
                    {name: "Bob", position: "Designer"}
                ]
            };

            console.log(company.address.city); // Output: Bangkok
  • optional: ค่าที่ไม่จำเป็นต้องมีใน Object

    • สามารถใช้ operator `?.` เพื่อตรวจสอบว่าคีย์มีอยู่จริงหรือไม่ก่อนเข้าถึงค่า

                let user = {
                name: "Charlie",
                address: {
                    city: "Chiang Mai"
                }
            };

            console.log(user.address?.city); // Output: Chiang Mai
            console.log(user.contact?.phone); // Output: undefined (ไม่เกิดข้อผิดพลาด)

ประเภทข้อมูล Reference

Reference Types คือ ประเภทข้อมูลที่เก็บการอ้างอิงไปยังตำแหน่งของข้อมูลในหน่วยความจำ แทนที่จะเก็บค่าของข้อมูลโดยตรง

  • Object: เป็น Reference Type ที่เก็บค่าคู่ของคีย์และค่า
    •             let obj1 = {name: "Dave"}; 
            let obj2 = obj1; 
            obj2.name = "Eve"; // obj1.name จะเป็น "Eve"
  • Array: เป็น Reference Type ที่เก็บกลุ่มของข้อมูลในรูปแบบลำดับ
    •             let arr1 = [1, 2, 3]; 
            let arr2 = arr1; 
            arr2.push(4); // arr1 จะเป็น [1, 2, 3, 4]
  • Function: เป็น Reference Type ที่เก็บชุดคำสั่งที่สามารถเรียกใช้งานได้
    •             let func1 = function() { return "Hello"; }; 
            let func2 = func1; console.log(func2()); // Output: Hello
  • ปัญหาประเภทข้อมูล Reference

    • เมื่อทำการคัดลอกตัวแปรที่เป็น Reference Type จะเป็นการคัดลอกการอ้างอิงไปยังตำแหน่งของข้อมูลในหน่วยความจำ ไม่ใช่การคัดลอกค่าของข้อมูลจริงๆ ดังนั้น การเปลี่ยนแปลงค่าผ่านตัวแปรที่คัดลอกจะส่งผลกระทบต่อตัวแปรต้นฉบับด้วย

                let originalArray = [1, 2, 3];
            let copiedArray = originalArray; // คัดลอกการอ้างอิง

            copiedArray.push(4); // เปลี่ยนแปลงค่าผ่าน copiedArray

            console.log(originalArray); // Output: [1, 2, 3, 4] (originalArray ถูกเปลี่ยนแปลงด้วย)
  • วิธีแก้ปัญหาประเภทข้อมูล Reference

    • สามารถใช้การคัดลอกแบบลึก (deep copy) เพื่อหลีกเลี่ยงปัญหาการเปลี่ยนแปลงค่าที่ส่งผลกระทบต่อตัวแปรต้นฉบับ

                let originalArray = [1, 2, 3];
            let copiedArray = [...originalArray]; // ใช้ spread operator เพื่อสร้างคัดลอกใหม่

            copiedArray.push(4); // เปลี่ยนแปลงค่าผ่าน copiedArray

            console.log(originalArray); // Output: [1, 2, 3] (originalArray ไม่ถูกเปลี่ยนแปลง)

Call property: ตัวอย่างการเรียกค่าใน Object

        let car = {
            brand: "Toyota",
            model: "Corolla",
            year: 2020,
            color: "Red"
        };

        console.log(car.brand); // Output: Toyota
        console.log(car["model"]); // Output: Corolla

Call method: ตัวอย่างการเรียกใช้เมธอดใน Object

        let calculator = {
            add: function(a, b) {
                return a + b;
            },
            subtract: function(a, b) {
                return a - b;
            }
        };

        console.log(calculator.add(5, 3)); // Output: 8
        console.log(calculator.subtract(10, 4)); // Output: 6

Dynamic Types

JavaScript เป็นภาษาที่มี Dynamic Types หมายความว่าตัวแปรสามารถเก็บค่าประเภทต่างๆ ได้ตามที่กำหนดในขณะรันไทม์

  • ตัวแปรสามารถเปลี่ยนประเภทข้อมูลได้ตามค่าที่ถูกกำหนดใหม่

    • let data = 10; // data เป็น Number data = "Hello"; // data เปลี่ยนเป็น String

  • การตรวจสอบประเภทข้อมูล: ใช้คำสั่ง typeof เพื่อตรวจสอบประเภทข้อมูลของตัวแปร

    • let type = typeof data;

การแปลงประเภทข้อมูล

JavaScript มีฟังก์ชันสำหรับแปลงประเภทข้อมูลต่างๆ ดังนี้

  • Explicit: การแปลงประเภทข้อมูลแบบชัดเจน คือการแปลงประเภทข้อมูลด้วยฟังก์ชันที่กำหนดเอง
    •             let num = Number("123"); // แปลง String เป็น Number
            let str = String(456);   // แปลง Number เป็น String
            let bool = Boolean(1);   // แปลง Number เป็น Boolean (true)
            let parseIntValue = parseInt("789"); // แปลง String เป็น จำนวนเต็ม
            let parseFloatValue = parseFloat("3.14"); // แปลง String เป็น ทศนิยม
  • Implicit: การแปลงประเภทข้อมูลแบบอัตโนมัติ คือการแปลงประเภทข้อมูลที่เกิดขึ้นโดยอัตโนมัติเมื่อมีการดำเนินการกับค่าต่างประเภท เช่น การบวก String กับ Number
    •             let result = "The answer is " + 42; // Number ถูกแปลงเป็น String อัตโนมัติ
  • Shot-Circuit Evaluation: การประเมินค่าแบบสั้น ซึ่งใช้ในเงื่อนไขที่มีการเชื่อมโยงด้วย && หรือ || โดยจะหยุดการประเมินเมื่อได้ผลลัพธ์ที่แน่นอนแล้ว
    •             let a = true && false; // ประเมินค่าเป็น false ทันที
            let b = false || true; // ประเมินค่าเป็น true ทันที
  • ปัญหาการเทียบค่า: บางครั้งการเทียบค่าระหว่างประเภทข้อมูลที่แตกต่างกันอาจทำให้เกิดผลลัพธ์ที่ไม่คาดคิด เช่น การเทียบ String กับ Number
    •             let isEqual = "5" == 5; // true เพราะ String ถูกแปลงเป็น Number อัตโนมัติ
            let isStrictEqual = "5" === 5; // false เพราะประเภทข้อมูลไม่ตรงกัน

กำหนดเงื่อนไขการทำงาน

ใช้คำสั่ง if, else if, else เพื่อกำหนดเงื่อนไขการทำงานของโปรแกรม

        let age = 20;

        if (age >= 18) {
            console.log("You are an adult.");
        } else if (age >= 13) {
            console.log("You are a teenager.");
        } else {
            console.log("You are a child.");
        }

Shorthand: ใช้การเขียนแบบสั้นๆ ของ if-else โดยใช้ operator แบบ ternary

        let age = 20;
        let status = age >= 18 ? "adult" : "child";
        console.log(status); // Output: adult

ใช้คำสั่ง switch-case เพื่อจัดการหลายเงื่อนไข

        let day = 3;
        let dayName;

        switch (day) {
            case 1:
                dayName = "Monday";
                break;
            case 2:
                dayName = "Tuesday";
                break;
            case 3:
                dayName = "Wednesday";
                break;
            case 4:
                dayName = "Thursday";
                break;
            case 5:
                dayName = "Friday";
                break;
            case 6:
                dayName = "Saturday";
                break;
            case 7:
                dayName = "Sunday";
                break;
            default:
                dayName = "Invalid day";
        }

        console.log(dayName); // Output: Wednesday

การวนลูป

ใช้คำสั่งวนลูปเพื่อทำซ้ำชุดคำสั่งจนกว่าจะถึงเงื่อนไขที่กำหนด

  • for: ใช้สำหรับการวนลูปที่มีจำนวนครั้งแน่นอน
    •             for (let i = 0; i < 5; i++) {
                console.log("Iteration " + i);
            }
  • while: ใช้สำหรับการวนลูปที่ขึ้นอยู่กับเงื่อนไข
    •             let i = 0;
            while (i < 5) {
                console.log("Iteration " + i);
                i++;
            }
  • do...while: คล้ายกับ while แต่จะทำคำสั่งอย่างน้อยหนึ่งครั้งก่อนตรวจสอบเงื่อนไข
    •             let i = 0;
            do {
                console.log("Iteration " + i);
                i++;
            } while (i < 5);
  • for...in: ใช้สำหรับวนลูปผ่านคีย์ของ Object
    •             let person = {name: "Alice", age: 25, city: "Bangkok"};
            for (let key in person) {
                console.log(key + ": " + person[key]);
            }
  • for...of: ใช้สำหรับวนลูปผ่านค่าของ iterable เช่น Array
    •             let fruits = ["Apple", "Banana", "Cherry"];
            for (let fruit of fruits) {
                console.log(fruit);
            }
  • break: ใช้สำหรับออกจากลูป
    •             for (let i = 0; i < 5; i++) {
                if (i === 3) {
                    break;
                }
                console.log("Iteration " + i);
            }
  • continue: ใช้สำหรับข้ามการทำงานในรอบปัจจุบัน
    •             for (let i = 0; i < 5; i++) {
                if (i === 3) {
                    continue;
                }
                console.log("Iteration " + i);
            }

function

function เป็นกลุ่มของคำสั่งที่ทำงานร่วมกันเพื่อทำหน้าที่อย่างใดอย่างหนึ่ง โดยสามารถเรียกใช้งานได้หลายครั้ง

        function ชื่อฟังก์ชั่น(parameter1, parameter2, ...) {
            // code to be executed
        }

function with return value

function with return value เป็นกลุ่มของคำสั่งที่ทำงานร่วมกันเพื่อทำหน้าที่อย่างใดอย่างหนึ่ง โดยสามารถเรียกใช้งานได้หลายครั้ง

        function ชื่อฟังก์ชั่น(parameter1, parameter2, ...) {
            // code to be executed
            return value;
        }
