CSS คืออะไร

CSS ย่อมาจาก Cascading Style Sheets เป็นภาษาที่ใช้สำหรับการตกแต่งและจัดรูปแบบของเอกสาร HTML หรือ XML โดย CSS ช่วยให้เราสามารถควบคุมลักษณะการแสดงผลขององค์ประกอบต่าง ๆ บนหน้าเว็บ เช่น สี, ขนาดตัวอักษร, การจัดวางตำแหน่ง, และอื่น ๆ อีกมากมาย

วิธีการใช้งาน CSS

โครวสร้าง CSS

CSS ประกอบด้วยกฎ (rules) ที่ประกอบด้วยตัวเลือก (selector) และการประกาศ (declaration) ซึ่งการประกาศจะประกอบด้วยคุณสมบัติ (property) และค่า (value)


    selector {
        property: value;
    }

วิธีการใช้งาน CSS

มีสามวิธีหลักในการใช้ CSS กับเอกสาร HTML:

  1. Inline CSS: การใส่สไตล์โดยตรงในแท็ก HTML โดยใช้แอตทริบิวต์ style
    2. <h1 style="color: blue; font-size: 24px;">Hello World</h1>
  2. Internal CSS: การใส่สไตล์ภายในแท็ก <style> ในส่วนหัวของเอกสาร HTML
    3. <head>
    <style>
        h1 {
            color: blue;
            font-size: 24px;
        }
    </style>
</head>
  3. External CSS: การเชื่อมโยงไฟล์ CSS ภายนอกกับเอกสาร HTML โดยใช้แท็ก <link>
    4. <head>
    <link rel="stylesheet" href="styles.css">
</head>

ตัวอย่างการใช้ CSS

  • Inline

    •             <li style="color: red; font-size: 24px;">Inline</li>

  • Internal

    •         <style>
            li {
                color: blue;
                font-size: 24px;
            }
        </style>

  • External

    •         <head>
            <link rel="stylesheet" href="styles.css">
        </head>

แนวทางการใช้ Selector

Selector เป็นส่วนที่ใช้ในการเลือกองค์ประกอบ HTML ที่เราต้องการจะตกแต่ง ตัวอย่างของ Selector ที่ใช้บ่อยได้แก่:

  • Element Selector: เลือกองค์ประกอบตามชื่อแท็ก เช่น h1, p, div
    • 
        h1 {
            color: green;
        }
  • Class Selector: เลือกองค์ประกอบที่มีคลาสเฉพาะ โดยใช้จุด (.) ตามด้วยชื่อคลาส
    • 
        .my-class {
            font-size: 18px;
        }
  • ID Selector: เลือกองค์ประกอบที่มี ID เฉพาะ โดยใช้เครื่องหมายแฮช (#) ตามด้วยชื่อ ID
    • 
        #my-id {
            background-color: yellow;
        }
  • Attribute Selector: เลือกองค์ประกอบที่มีคุณสมบัติเฉพาะ เช่น input[type="text"]
    • 
        input[type="text"] {
            border: 1px solid #ccc;
        }
  • Universal Selector: เลือกองค์ประกอบทุกตัวในหน้าเว็บ โดยใช้เครื่องหมาย *
    • 
        * {
            margin: 0;
            padding: 0;
        }
  • Inherited: คุณสมบัติที่ถูกสืบทอดจากองค์ประกอบแม่ไปยังองค์ประกอบลูก เช่น สีตัวอักษรและแบบอักษร
    • 
        body {
            color: black;
            font-family: Arial, sans-serif;
        }
  • Compound Selector: การรวมกันของหลายๆ Selector เพื่อเลือกองค์ประกอบที่ตรงตามเงื่อนไขทั้งหมด
    • 
        div.my-class {
            border: 1px solid black;
        }
  • Combinator Selector: การเลือกองค์ประกอบตามความสัมพันธ์ระหว่างองค์ประกอบ เช่น parent-child หรือ sibling
    • 
        div > p {
            color: purple;
        }
  • Child Selector: เลือกองค์ประกอบลูกที่เป็นลูกโดยตรงขององค์ประกอบแม่
    • 
        ul > li {
            list-style-type: square;
        }
  • Sibling Selector: เลือกองค์ประกอบที่อยู่ข้างๆ กันในลำดับเดียวกัน เช่น p + p หรือ p ~ p
    • 
        h1 + p {
            margin-top: 0;
        }
  • Nesting Selector: การเลือกองค์ประกอบภายในองค์ประกอบอื่นๆ โดยใช้การซ้อนกันของ Selector
    • 
        table.with-style{
            border-collapse: collapse;
            thead {
                background-color: #f2f2f2;
            }
            tbody {
                tr {
                    border-bottom: 1px solid #ddd;
                }
            }
        }

คะแนนของ specificity

Specificity คือระบบการให้คะแนนเพื่อกำหนดว่า CSS rule ใดจะถูกนำไปใช้เมื่อมีหลายๆ rule ที่ตรงกับองค์ประกอบเดียวกัน โดยมีหลักการดังนี้:

  • Inline styles (เช่น style="...") มีคะแนนสูงสุด (1000)
  • ID selectors (#id) มีคะแนนถัดมา (100)
  • Class selectors (.class), attribute selectors ([type="text"]), และ pseudo-classes (:hover) มีคะแนนเท่ากัน (10)
  • Element selectors (div, p, h1) และ pseudo-elements (::before, ::after) มีคะแนนต่ำสุด (1)
  • !important มีคะแนนสูงสุด (1000)

เมื่อมีหลายๆ rule ที่ตรงกับองค์ประกอบเดียวกัน จะนำคะแนน specificity มาคำนวณเพื่อเลือก rule ที่มีคะแนนสูงสุดมาใช้

แนวทางการใช้ Pseudo-classes และ Pseudo-elements

Pseudo-classes และ Pseudo-elements เป็นเครื่องมือที่ช่วยให้เราสามารถเลือกและตกแต่งองค์ประกอบ HTML ในสถานะหรือรูปแบบพิเศษได้

Pseudo-classes

Pseudo-classes ใช้เพื่อเลือกองค์ประกอบในสถานะพิเศษ เช่น เมื่อเมาส์ชี้, เมื่อองค์ประกอบถูกโฟกัส หรือเมื่อองค์ประกอบเป็นลูกคนแรกของพาเรนต์ ตัวอย่างของ Pseudo-classes ได้แก่:

  • :hover - เลือกองค์ประกอบเมื่อเมาส์ชี้
    ตัวอย่าง
  • :focus - เลือกองค์ประกอบเมื่อได้รับโฟกัส
  • :active - เลือกองค์ประกอบเมื่อถูกคลิกหรืออยู่ในสถานะ active
    ตัวอย่าง
  • :visited - เลือกองค์ประกอบที่ถูกเยี่ยมชมแล้ว
    ตัวอย่าง
  • :first-child - เลือกองค์ประกอบที่เป็นลูกคนแรกของพาเรนต์
    ตัวอย่าง
  • :nth-child(n) - เลือกองค์ประกอบที่เป็นลูกลำดับที่ n ของพาเรนต์
    ตัวอย่าง

Pseudo-elements

Pseudo-elements ใช้เพื่อสร้างองค์ประกอบเสมือนที่ไม่ได้อยู่ในโครงสร้าง HTML แต่สามารถตกแต่งได้ ตัวอย่างของ Pseudo-elements ได้แก่:

  • ::before - สร้างเนื้อหาก่อนองค์ประกอบที่เลือก
  • ::after - สร้างเนื้อหาหลังองค์ประกอบที่เลือก
  • ::first-letter - เลือกตัวอักษรตัวแรกขององค์ประกอบ
  • ::first-line - เลือกบรรทัดแรกขององค์ประกอบ

การกำหนดรูปแบบข้อความ

CSS มีคุณสมบัติหลายอย่างที่ช่วยให้เราสามารถกำหนดรูปแบบข้อความได้อย่างละเอียด ตัวอย่างของคุณสมบัติที่ใช้บ่อยได้แก่:

  • color: กำหนดสีของข้อความ
    • สีอื่นๆ
  • font-family: กำหนดแบบอักษรของข้อความ
    • ฟอนต์อื่นๆ
  • font-size: กำหนดขนาดตัวอักษร
  • font-weight: กำหนดความหนาของตัวอักษร (เช่น normal, bold)
  • text-align: กำหนดการจัดแนวของข้อความ (เช่น left, center, right)
  • text-decoration: กำหนดการตกแต่งข้อความ (เช่น underline, line-through)
  • line-height: กำหนดระยะห่างระหว่างบรรทัดของข้อความ

Box Model

Box Model เป็นแนวคิดพื้นฐานใน CSS ที่อธิบายถึงโครงสร้างขององค์ประกอบ HTML แต่ละตัว ซึ่งประกอบด้วยส่วนต่างๆ ดังนี้:

  • Content: เนื้อหาภายในกล่อง เช่น ข้อความหรือรูปภาพ
  • Padding: พื้นที่ว่างระหว่างเนื้อหากับขอบของกล่อง
  • Border: ขอบของกล่องที่ล้อมรอบ Padding และ Content
  • Margin: พื้นที่ว่างระหว่างกล่องกับองค์ประกอบอื่นๆ รอบข้าง

text

เราสามารถกำหนดค่าต่างๆ ของ Box Model ได้ผ่านคุณสมบัติต่างๆ ใน CSS เช่น:

  • width: กำหนดความกว้างของกล่อง
  • height: กำหนดความสูงของกล่อง
  • padding: กำหนดพื้นที่ว่างภายในกล่อง
  • border: กำหนดลักษณะของขอบกล่อง
    • border-width: กำหนดความหนาของขอบกล่อง
    • border-style: กำหนดรูปแบบของขอบกล่อง (เช่น solid, dashed, dotted)
    • border-color: กำหนดสีของขอบกล่อง
    • border-radius: กำหนดรูปร่างของขอบกล่อง (เช่น วงกลม)
  • margin: กำหนดพื้นที่ว่างภายนอกกล่อง
  • outline: กำหนดเส้นขอบภายนอกของกล่อง
  • left: กำหนดตำแหน่งด้านซ้ายของกล่อง
  • right: กำหนดตำแหน่งด้านขวาของกล่อง
  • top: กำหนดตำแหน่งด้านบนของกล่อง
  • bottom: กำหนดตำแหน่งด้านล่างของกล่อง
  • box-shadow: กำหนดเงาของกล่อง
  • overflow: กำหนดการจัดการเนื้อหาที่เกินขอบของกล่อง
    • overflow-x: กำหนดการจัดการเนื้อหาที่เกินขอบด้านซ้ายและขวา
    • overflow-y: กำหนดการจัดการเนื้อหาที่เกินขอบด้านบนและล่าง

เทคนิคพิเศษเกี่ยวกับพื้นหลังและรูปภาพ

CSS มีคุณสมบัติหลายอย่างที่ช่วยให้เราสามารถกำหนดลักษณะของพื้นหลังและรูปภาพได้อย่างสร้างสรรค์ ตัวอย่างของคุณสมบัติที่ใช้บ่อยได้แก่:

  • background-color: กำหนดสีพื้นหลังขององค์ประกอบ
  • background-image: กำหนดรูปภาพพื้นหลังขององค์ประกอบ
  • background-size: กำหนดขนาดของรูปภาพพื้นหลัง (เช่น cover, contain)
  • background-position: กำหนดตำแหน่งของรูปภาพพื้นหลัง (เช่น center, top right)
  • background-repeat: กำหนดการทำซ้ำของรูปภาพพื้นหลัง (เช่น no-repeat, repeat-x)
  • background-attachment: กำหนดว่าพื้นหลังจะเคลื่อนไหวหรือไม่เมื่อผู้ใช้เลื่อนหน้าต่าง
  • backdrop-filter: ใช้เพื่อเพิ่มเอฟเฟกต์พิเศษให้กับพื้นหลังขององค์ประกอบ เช่น blur
  • background: radial-gradient; กำหนดสีพื้นหลังแบบ radial gradient
    • สำหรับหาสีพื้นหลัง
  • opacity: กำหนดความโปร่งใสขององค์ประกอบ
  • filter: ใช้สำหรับเพิ่มเอฟเฟกต์พิเศษให้กับรูปภาพ เช่น blur, grayscale
  • object-fit: กำหนดวิธีการปรับขนาดของรูปภาพภายในกล่อง

layout แบบ Flexbox

Flexbox (Flexible Box Layout) เป็นเทคนิคการจัดวางองค์ประกอบใน CSS ที่ช่วยให้เราสามารถจัดการกับการจัดวางและการจัดตำแหน่งขององค์ประกอบภายในคอนเทนเนอร์ได้อย่างง่ายดายและยืดหยุ่น

องประกอบของ Flexbox ได้แก่:

  • container: คอนเทนเนอร์ที่ใช้ในการจัดวางองค์ประกอบ
  • items: องค์ประกอบภายในคอนเทนเนอร์ที่ถูกจัดวาง

คุณสมบัติหลักของ Flexbox ได้แก่:

  • display: flex; กำหนดให้คอนเทนเนอร์เป็น Flexbox
  • flex-direction: กำหนดทิศทางการจัดวางองค์ประกอบ
    • row: จัดวางองค์ประกอบในแนวนอนจากซ้ายไปขวา
    • column: จัดวางองค์ประกอบในแนวตั้งจากบนลงล่าง
  • justify-content: กำหนดการจัดตำแหน่งในแนวนอนขององค์ประกอบภายในคอนเทนเนอร์
    • flex-start: จัดวางองค์ประกอบที่ด้านซ้ายของคอนเทนเนอร์
    • flex-end: จัดวางองค์ประกอบที่ด้านขวาของคอนเทนเนอร์
    • center: จัดวางองค์ประกอบที่ตรงกลางของคอนเทนเนอร์
    • space-between: จัดวางองค์ประกอบให้มีช่องว่างระหว่างกัน
    • space-around: จัดวางองค์ประกอบให้มีช่องว่างรอบๆ
  • align-items: กำหนดการจัดตำแหน่งในแนวตั้งขององค์ประกอบภายในคอนเทนเนอร์
    • flex-start: จัดวางองค์ประกอบที่ด้านบนของคอนเทนเนอร์
    • flex-end: จัดวางองค์ประกอบที่ด้านล่างของคอนเทนเนอร์
    • center: จัดวางองค์ประกอบที่ตรงกลางของคอนเทนเนอร์
    • stretch: ขยายองค์ประกอบให้เต็มความสูงของคอนเทนเนอร์
  • flex-wrap: กำหนดว่าควรให้บรรทัดใหม่เกิดขึ้นเมื่อองค์ประกอบเกินขนาดคอนเทนเนอร์หรือไม่
  • flex-grow: กำหนดว่าองค์ประกอบสามารถขยายตัวได้มากน้อยเพียงใดเมื่อมีพื้นที่ว่างในคอนเทนเนอร์
  • flex-shrink: กำหนดว่าองค์ประกอบสามารถหดตัวได้มากน้อยเพียงใดเมื่อไม่มีพื้นที่เพียงพอในคอนเทนเนอร์
  • align-self: กำหนดการจัดตำแหน่งขององค์ประกอบแต่ละตัวแยกจากกัน

layout แบบ Grid

CSS Grid Layout เป็นเทคนิคการจัดวางองค์ประกอบในรูปแบบตารางที่ช่วยให้เราสามารถสร้างเลย์เอาต์ที่ซับซ้อนได้อย่างง่ายดายและยืดหยุ่น

องค์ประกอบของ Grid ได้แก่:

  • grid container: คอนเทนเนอร์ที่ใช้ในการจัดวางองค์ประกอบในรูปแบบตาราง
  • grid items: องค์ประกอบภายในคอนเทนเนอร์ที่ถูกจัดวางในรูปแบบตาราง

คุณสมบัติหลักของ Grid ได้แก่:

  • display: grid; กำหนดให้คอนเทนเนอร์เป็น Grid
  • grid-template-columns: กำหนดจำนวนและขนาดของคอลัมน์ในตาราง
  • grid-template-rows: กำหนดจำนวนและขนาดของแถวในตาราง
  • grid-gap: กำหนดระยะห่างระหว่างแถวและคอลัมน์ในตาราง
  • justify-items: กำหนดการจัดตำแหน่งในแนวนอนขององค์ประกอบภายในกริด
  • align-items: กำหนดการจัดตำแหน่งในแนวตั้งขององค์ประกอบภายในกริด
  • grid-column: กำหนดตำแหน่งและขนาดขององค์ประกอบในแนวนอน
  • grid-row: กำหนดตำแหน่งและขนาดขององค์ประกอบในแนวตั้ง

layout แบบ Column

CSS Multi-column Layout เป็นเทคนิคการจัดวางองค์ประกอบในรูปแบบหลายคอลัมน์ที่ช่วยให้เราสามารถสร้างเลย์เอาต์ที่มีลักษณะคล้ายกับหนังสือพิมพ์หรือนิตยสารได้อย่างง่ายดาย

คุณสมบัติหลักของ Multi-column ได้แก่:

  • column-count: กำหนดจำนวนคอลัมน์ที่ต้องการให้แสดง
  • column-width: กำหนดความกว้างของแต่ละคอลัมน์
  • column-gap: กำหนดระยะห่างระหว่างคอลัมน์
  • column-rule: กำหนดเส้นแบ่งระหว่างคอลัมน์

เทคนิคการใช้ Positioning

CSS Positioning เป็นเทคนิคที่ช่วยให้เราสามารถกำหนดตำแหน่งขององค์ประกอบบนหน้าเว็บได้อย่างแม่นยำ โดยใช้คุณสมบัติต่างๆ เช่น:

  • position: กำหนดวิธีการจัดวางองค์ประกอบ
    • static: องค์ประกอบจะจัดวางตามลำดับปกติของหน้าเว็บ
    • relative: องค์ประกอบจะจัดวางตามลำดับปกติของหน้าเว็บ แต่สามารถปรับตำแหน่งได้โดยใช้ค่า top, right, bottom, left
    • absolute: องค์ประกอบจะจัดวางตามตำแหน่งที่กำหนดโดยใช้ค่า top, right, bottom, left ซึ่งอ้างอิงจากพื้นที่ของพาเรนต์ที่มี position: relative
    • fixed: องค์ประกอบจะจัดวางตามตำแหน่งที่กำหนดโดยใช้ค่า top, right, bottom, left ซึ่งอ้างอิงจากหน้าต่างเบราว์เซอร์
    • sticky: องค์ประกอบจะจัดวางตามลำดับปกติของหน้าเว็บ แต่เมื่อผู้ใช้เลื่อนหน้าเว็บไปถึงตำแหน่งที่กำหนด จะกลายเป็น fixed
  • top, right, bottom, left: กำหนดระยะห่างจากขอบของพาเรนต์หรือหน้าต่างเบราว์เซอร์ ขึ้นอยู่กับค่าของ position
  • z-index: กำหนดลำดับชั้นขององค์ประกอบเมื่อมีการซ้อนทับกัน

ปรับเปลี่ยนเนื้อหาแบบ Transition และการเปลี่ยนรูปร่าง Transform

CSS Transition และ Transform เป็นเทคนิคที่ช่วยให้เราสามารถสร้างเอฟเฟกต์การเปลี่ยนแปลงและการเคลื่อนไหวขององค์ประกอบบนหน้าเว็บได้อย่างน่าสนใจ

คุณสมบัติหลักของ Transition ได้แก่:

  • transition-property: กำหนดคุณสมบัติที่ต้องการให้เกิดการเปลี่ยนแปลง
  • transition-duration: กำหนดระยะเวลาที่ใช้ในการเปลี่ยนแปลง
  • transition-timing-function: กำหนดรูปแบบของการเปลี่ยนแปลง
    • ease: การเปลี่ยนแปลงเริ่มต้นช้า เร็วขึ้นในช่วงกลาง และช้าลงเมื่อสิ้นสุด
    • linear: การเปลี่ยนแปลงที่มีความเร็วคงที่ตลอดเวลา
    • ease-in: การเปลี่ยนแปลงที่เริ่มต้นช้าและเร่งความเร็วขึ้นเมื่อสิ้นสุด
    • ease-out: การเปลี่ยนแปลงที่เริ่มต้นเร็วและช้าลงเมื่อสิ้นสุด
  • transition-delay: กำหนดเวลาหน่วงก่อนที่จะเริ่มการเปลี่ยนแปลง

คุณสมบัติหลักของ Transform ได้แก่:

  • transform: translate(x, y); ย้ายองค์ประกอบไปยังตำแหน่งใหม่ตามแกน x และ y
  • transform: rotate(angle); หมุนองค์ประกอบตามมุมที่กำหนด
  • transform: scale(sx, sy); ปรับขนาดองค์ประกอบตามแกน x และ y
  • transform: skew(ax, ay); เอียงองค์ประกอบตามแกน x และ y

การใช้งาน Animation

CSS Animation เป็นเทคนิคที่ช่วยให้เราสามารถสร้างการเคลื่อนไหวขององค์ประกอบบนหน้าเว็บได้อย่างน่าสนใจ โดยใช้คุณสมบัติหลักดังนี้:

  • @keyframes: กำหนดชุดของขั้นตอนการเปลี่ยนแปลงที่ต้องการให้เกิดขึ้นในระหว่างการเคลื่อนไหว
    •         @keyframes example {
            0% { background-color: red; }
            50% { background-color: yellow; }
            100% { background-color: green; }
        }
  • animation-name: กำหนดชื่อของชุดขั้นตอนที่ต้องการใช้
  • animation-duration: กำหนดระยะเวลาที่ใช้ในการเคลื่อนไหว
  • animation-timing-function: กำหนดรูปแบบของการเคลื่อนไหว
  • animation-delay: กำหนดเวลาหน่วงก่อนที่จะเริ่มการเคลื่อนไหว
  • animation-iteration-count: กำหนดจำนวนครั้งที่ต้องการให้การเคลื่อนไหวเกิดขึ้น
  • animation-direction: กำหนดทิศทางของการเคลื่อนไหว
    • normal: การเคลื่อนไหวจะเกิดขึ้นจากจุดเริ่มต้นไปยังจุดสิ้นสุด
    • reverse: การเคลื่อนไหวจะเกิดขึ้นจากจุดสิ้นสุดกลับไปยังจุดเริ่มต้น
    • alternate: การเคลื่อนไหวจะสลับทิศทางในแต่ละรอบ

วิธีการออกแบบเว็บให้ตอบสนอง (Responsive Web Design)

Responsive Web Design เป็นแนวทางการออกแบบเว็บไซต์ที่ช่วยให้เว็บไซต์สามารถปรับตัวและแสดงผลได้อย่างเหมาะสมบนอุปกรณ์ที่มีขนาดหน้าจอแตกต่างกัน เช่น คอมพิวเตอร์เดสก์ท็อป, แท็บเล็ต, และสมาร์ทโฟน

เทคนิคหลักในการสร้าง Responsive Web Design ได้แก่:

  • Media Queries: ใช้เพื่อกำหนดสไตล์ที่แตกต่างกันตามขนาดหน้าจอของอุปกรณ์
    • 
        @media (max-width: 600px) {
            body {
                background-color: lightblue;
            }
        }
  • Flexible Grid Layouts: ใช้ระบบกริดที่ยืดหยุ่นเพื่อจัดวางองค์ประกอบบนหน้าเว็บ
  • Flexible Images and Media: ใช้คุณสมบัติ CSS เช่น max-width: 100%; เพื่อให้รูปภาพและสื่ออื่นๆ ปรับขนาดตามขนาดของคอนเทนเนอร์
  • Viewport Meta Tag: ใช้แท็ก meta ในส่วนหัวของเอกสาร HTML เพื่อควบคุมการแสดงผลบนอุปกรณ์เคลื่อนที่
    • <meta name="viewport" content="width=device-width, initial-scale=1.0">
