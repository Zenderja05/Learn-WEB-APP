JAVASCRIPT

ตัวแปรใน JAVASCRIPT

ตัวแปรใน JavaScript คือพื้นที่ที่ใช้เก็บข้อมูลหรือค่าต่างๆ ที่สามารถเปลี่ยนแปลงได้ในระหว่างการทำงานของโปรแกรม

  • var - ตัวแปรที่มีขอบเขตการใช้งานในฟังก์ชันหรือสคริปต์ทั้งหมด
    • var name = "John";
  • let - ตัวแปรที่มีขอบเขตการใช้งานในบล็อกที่ถูกประกาศ
    • let name = "John";
  • const - ตัวแปรที่ไม่สามารถเปลี่ยนแปลงค่าได้หลังจากที่ถูกประกาศ
    • const name = "John";

ประเภทข้อมูลใน JAVASCRIPT

JavaScript มีประเภทข้อมูลหลักๆ ดังนี้

  • String - ข้อความที่ใช้เก็บข้อมูลในรูปแบบของตัวอักษร
  • Number - ตัวเลขที่ใช้เก็บข้อมูลในรูปแบบของตัวเลข
  • Boolean - ค่าที่มีค่าเป็น true หรือ false
  • Undefined - ค่าที่ยังไม่ได้กำหนดค่าให้กับตัวแปร
  • null - ค่าที่มีค่าเป็น null (ไม่มีค่า)

การเปรียบเทียบใน JAVASCRIPT

การเปรียบเทียบใน JavaScript ใช้ในการตรวจสอบความสัมพันธ์ระหว่างค่าต่างๆ

  • == - เปรียบเทียบค่าโดยไม่สนใจชนิดข้อมูล (loose equality)
  • === - เปรียบเทียบค่าและชนิดข้อมูล (strict equality)
  • != - เปรียบเทียบค่าโดยไม่สนใจชนิดข้อมูล (loose inequality)
  • !== - เปรียบเทียบค่าและชนิดข้อมูล (strict inequality)
  • > - เปรียบเทียบว่าค่าซ้ายมากกว่าค่าขวาหรือไม่
  • < - เปรียบเทียบว่าค่าซ้ายน้อยกว่าค่าขวาหรือไม่
  • >= - เปรียบเทียบว่าค่าซ้ายมากกว่าหรือเท่ากับค่าขวาหรือไม่
  • <= - เปรียบเทียบว่าค่าซ้ายน้อยกว่าหรือเท่ากับค่าขวาหรือไม่

เงื่อนไขใน JAVASCRIPT

เงื่อนไขใน JavaScript ใช้ในการตัดสินใจว่าจะทำอะไรต่อไปตามค่าของตัวแปรหรือผลลัพธ์ของการเปรียบเทียบ

  • if - ใช้ในการตรวจสอบเงื่อนไขและทำงานเมื่อเงื่อนไขเป็นจริง
  • else - ใช้ในการทำงานเมื่อเงื่อนไขใน if เป็นเท็จ
  • else if - ใช้ในการตรวจสอบเงื่อนไขเพิ่มเติมเมื่อเงื่อนไขใน if เป็นเท็จ
if (age >= 18) {
    console.log("You are an adult.");
} 
else if (age >= 13) {
    console.log("You are a teenager.");
} 
else {
    console.log("You are a child.");
}

ลูปใน JAVASCRIPT

ลูปใน JavaScript ใช้ในการทำซ้ำคำสั่งหรือบล็อกของโค้ดตามจำนวนครั้งที่กำหนดหรือจนกว่าเงื่อนไขจะเป็นเท็จ

  • for - ใช้ในการทำซ้ำคำสั่งตามจำนวนครั้งที่กำหนด
    • for (let i = 0; i < 5; i++) {
    console.log(i);
}
  • while - ใช้ในการทำซ้ำคำสั่งจนกว่าเงื่อนไขจะเป็นเท็จ
    • let i = 0;
while (i < 5) {
    console.log(i);
    i++;
}
  • do...while - ใช้ในการทำซ้ำคำสั่งอย่างน้อยหนึ่งครั้งและตรวจสอบเงื่อนไขหลังจากนั้น
    • let i = 0;
do {
    console.log(i);
    i++;
} while (i < 5);

ฟังก์ชันใน JAVASCRIPT

ฟังก์ชันใน JavaScript คือชุดของคำสั่งที่ถูกกำหนดให้ทำงานเมื่อถูกเรียกใช้

  • Function Declaration - การประกาศฟังก์ชันโดยใช้คำสั่ง function
    • function greet(name) {
    return "Hello, " + name + "!";
}
  • Function Expression - การประกาศฟังก์ชันโดยการกำหนดให้ตัวแปรเป็นฟังก์ชัน
    • const greet = function(name) {
    return "Hello, " + name + "!";
};
  • Arrow Function - การประกาศฟังก์ชันโดยใช้เครื่องหมายลูกศร (=>)
    • const greet = (name) => {
    return "Hello, " + name + "!";
};

อาเรย์และออบเจกต์ใน JAVASCRIPT

อาเรย์ (Array) คือโครงสร้างข้อมูลที่ใช้เก็บค่าหลายค่าในลำดับเดียวกัน

const fruits = ["Apple", "Banana", "Cherry"];

ออบเจกต์ (Object) คือโครงสร้างข้อมูลที่ใช้เก็บค่าหลายค่าในรูปแบบของ key-value pairs

const person = {
    name: "John",
    age: 30,
    city: "New York"
};

DOM (Document Object Model)

DOM คือวิธีการเข้าถึงและจัดการกับเนื้อหาของหน้าเว็บ HTML ผ่าน JavaScript

การเลือก Element

  • getElementById - ใช้ในการเลือกองค์ประกอบโดยใช้ ID
    • const element = document.getElementById("myElement");
  • getElementsByClassName - ใช้ในการเลือกองค์ประกอบโดยใช้ class name
    • const elements = document.getElementsByClassName("myClass");
  • querySelector - ใช้ในการเลือกองค์ประกอบโดยใช้ CSS selector
    • const element = document.querySelector(".myClass");
  • querySelectorAll - ใช้ในการเลือกองค์ประกอบทั้งหมดที่ตรงกับ CSS selector
    • const elements = document.querySelectorAll(".myClass");

การแก้ไขเนื้อหา

  • textContent - ใช้ในการแก้ไขข้อความภายในองค์ประกอบ
    • element.textContent = "New Text";
  • innerHTML - ใช้ในการแก้ไขเนื้อหาภายในองค์ประกอบ รวมถึง HTML tags
    • element.innerHTML = "<strong>Bold Text</strong>";

การแก้ไข attribute

  • setAttribute - ใช้ในการตั้งค่า attribute ขององค์ประกอบ
    • element.setAttribute("class", "newClass");
  • getA ttribute - ใช้ในการดึงค่า attribute ขององค์ประกอบ
    • const className = element.getAttribute("class");
  • removeAttribute - ใช้ในการลบ attribute ขององค์ประกอบ
    • element.removeAttribute("class");

การจัดการ Class

  • classList.add - ใช้ในการเพิ่ม class ให้กับองค์ประกอบ
    • element.classList.add("newClass");
  • classList.remove - ใช้ในการลบ class จากองค์ประกอบ
    • element.classList.remove("oldClass");
  • classList.toggle - ใช้ในการสลับการมีอยู่ของ class ในองค์ประกอบ
    • element.classList.toggle("active");
  • classList.contains - ใช้ในการตรวจสอบว่าองค์ประกอบมี class นั้นอยู่หรือไม่
    • const hasClass = element.classList.contains("myClass");

การแก้ไข Style

  • style.property - ใช้ในการแก้ไขสไตล์ขององค์ประกอบโดยตรง
    • element.style.color = "red";

การสร้าง Element ใหม่

  • createElement - ใช้ในการสร้าง Element ใหม่
    • const newElement = document.createElement("div");
  • appendChild - ใช้ในการเพิ่ม Element ใหม่เข้าไปใน Element ที่มีอยู่
    • parentElement.appendChild(newElement);
  • removeChild - ใช้ในการลบ Element ออกจาก Element ที่มีอยู่
    • parentElement.removeChild(childElement);

Event Handling

Event Handling คือการจัดการกับเหตุการณ์ต่างๆ ที่เกิดขึ้นในหน้าเว็บ เช่น การคลิก การเลื่อนเมาส์ หรือการกดแป้นพิมพ์

  • addEventListener - ใช้ในการเพิ่ม event listener ให้กับองค์ประกอบ
    • element.addEventListener("click", function() {
    console.log("Element clicked!");
});
    D
  • removeEventListener - ใช้ในการลบ event listener จากองค์ประกอบ
    • element.removeEventListener("click", handleClick);
  • Event Object - ใช้ในการเข้าถึงข้อมูลเกี่ยวกับเหตุการณ์ที่เกิดขึ้น
    • element.addEventListener("click", function(event) {
    console.log("Mouse X: " + event.clientX);
    console.log("Mouse Y: " + event.clientY);
});
  • stopPropagation - ใช้ในการหยุดการส่งต่อ event ไปยังองค์ประกอบอื่น
    • element.addEventListener("click", function(event) {
    event.stopPropagation();
    console.log("Event stopped!");
});
  • preventDefault - ใช้ในการป้องกันพฤติกรรมเริ่มต้นของ event เช่น การลิงก์ไปยังหน้าใหม่
    • element.addEventListener("click", function(event) {
    event.preventDefault();
    console.log("Default behavior prevented!");
});

การเรียก API

การเรียก API คือการส่งคำขอไปยังเซิร์ฟเวอร์เพื่อรับข้อมูลหรือส่งข้อมูลไปยังเซิร์ฟเวอร์

  • พื้นฐานการใช้ fetch()
    • fetch(url, option)
    1. url - ระบุ URL ของ API ที่ต้องการเรียก
    2. option - ระบุตัวเลือก เช่น method, headers, body สำหรับคำขอ
  • GET Request
    • fetch(url, option)
    .then(response => response.json())
    .then(data => {
        console.log(data);
    })
    .catch(error => {
        console.error('Error:', error);
    });

    อธิบายขั้นตอน

    1. fetch() ส่ง HTTP request
    2. ได้ response กลับมา (ยังไม่ใช่ JSON)
    3. ต้องใช้ response.json() เพื่อแปลงเป็น JavaScript Object
    4. ได้ data
    5. .catch() ดัก error
  • async/await

    • คือ วิธีการจัดการกับ asynchronous operations ด้วยการใช้ async และ await ซึ่งทำให้โค้ดดูเหมือน synchronous

    async function getPost() {
    try {
        const response = await fetch(url, option);
            
            if (!response.ok) {
                throw new Error('HTTP error! status: ' + response.status);
            }
        
            const data = await response.json();
            console.log(data);
            } catch (error) {
            console.error('Error:', error);
        }
}
