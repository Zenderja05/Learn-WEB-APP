CSS

การเชื่อม CSS

การเชื่อม CSS มี 3 วิธีหลักๆ คือ

  • Inline CSS - การเขียน CSS ลงไปในแท็ก HTML โดยตรง
    •             <h1 style="color: red;">Hello World</h1>
  • Internal CSS - การเขียน CSS ภายในแท็ก <style>
    •             </head>
                <style>
                    h1 {
                        color: red;
                    }
                </style>
            <body>
  • External CSS - การเขียน CSS ในไฟล์แยกต่างหาก และเชื่อมโยงเข้ามาใน HTML
    •             <head>
                <link rel="stylesheet" href="styles.css">
            </head>

Selector

Selector คือส่วนที่ใช้เลือกองค์ประกอบใน HTML เพื่อกำหนดสไตล์ให้กับมัน

  • Element Selector - เลือกแท็ก HTML โดยตรง เช่น h1, p
    •             h1 {
                color: red;
            }
  • Class Selector - เลือกองค์ประกอบที่มี class ที่กำหนด
    •             .my-class {
                color: blue;
            }
  • ID Selector - เลือกองค์ประกอบที่มี id ที่กำหนด
    •             #my-id {
                color: green;
            }
  • Universal Selector - เลือกทุกองค์ประกอบใน HTML
    •             * {
                margin: 0;
                padding: 0;
            }
  • Attribute Selector - เลือกองค์ประกอบที่มีแอตทริบิวต์ที่กำหนด
    •             a[href="https://www.example.com"] {
                color: purple;
            }
  • Group Selector - เลือกหลายองค์ประกอบในครั้งเดียว
    •             h1, h2, h3 {
                color: blue;
            }
  • Descendant Selector - เลือกองค์ประกอบที่อยู่ภายในองค์ประกอบอื่น
    •             div p {
                color: red;
            }
  • Child Selector - เลือกองค์ประกอบที่เป็นลูกโดยตรงขององค์ประกอบอื่น
    •             div > p {
                color: green;
            }
  • Adjacent Sibling Selector - เลือกองค์ประกณ์ที่เป็นพี่น้องติดกันขององค์ประกอบอื่น
    •             h1 + p {
                color: blue;
            }
  • General Sibling Selector - เลือกองค์ประกณ์ที่เป็นพี่น้องขององค์ประกอบอื่น
    •             h1 ~ p {
                color: orange;
            }

Box Model

Box Model คือโมเดลที่ใช้ในการอธิบายการจัดวางและขนาดขององค์ประกอบใน HTML

  • Content - ส่วนที่แสดงเนื้อหาขององค์ประกอบ
  • Padding - พื้นที่ว่างระหว่างเนื้อหาและขอบขององค์ประกอบ
  • Border - ขอบขององค์ประกอบ

      • border จะมีการจัดเส้นขอบตามนี้

    1. solid - เส้นขอบที่มีลักษณะเป็นเส้นตรง
    2. dashed - เส้นขอบที่มีลักษณะเป็นเส้นประ
    3. dotted - เส้นขอบที่มีลักษณะเป็นจุด
    4. double - เส้นขอบที่มีลักษณะเป็นเส้นคู่
    5. groove - เส้นขอบที่มีลักษณะเป็นรูปโขด
  • Margin - พื้นที่ว่างระหว่างองค์ประกอบกับองค์ประกอบอื่นๆ

หน่วยใน CSS

ค่าของ CSS คือค่าที่ใช้กำหนดลักษณะขององค์ประกอบใน HTML

  • px - พิกเซล เป็นหน่วยที่ใช้วัดขนาดขององค์ประกอบในรูปแบบของพิกเซล
  • em - เป็นหน่วยที่ใช้วัดขนาดขององค์ประกอบโดยอิงจากขนาดของฟอนต์ในองค์ประกอบนั้น
  • rem - เป็นหน่วยที่ใช้วัดขนาดขององค์ประกอบโดยอิงจากขนาดของฟอนต์ใน root element (html)
  • % - เปอร์เซ็นต์ เป็นหน่วยที่ใช้วัดขนาดขององค์ประกอบโดยอิงจากขนาดขององค์ประกอบแม่
  • vw - Viewport Width เป็นหน่วยที่ใช้วัดขนาดขององค์ประกอบโดยอิงจากความกว้างของ viewport
  • vh - Viewport Height เป็นหน่วยที่ใช้วัดขนาดขององค์ประกอบโดยอิงจากความสูงของ viewport
  • vmin - เป็นหน่วยที่ใช้วัดขนาดขององค์ประกอบโดยอิงจากค่าที่น้อยที่สุดระหว่าง vw และ vh
  • vmax - เป็นหน่วยที่ใช้วัดขนาดขององค์ประกอบโดยอิงจากค่าที่มากที่สุดระหว่าง vw และ vh

Display Property

Display Property คือค่าที่ใช้กำหนดวิธีการแสดงองค์ประกอบใน HTML

  • block - องค์ประกอบจะแสดงเป็นบล็อก (แสดงในบรรทัดใหม่) เหมาะสำหรับ เลย์เอาท์หัวข้อ
  • inline - องค์ประกอบจะแสดงเป็นอินไลน์ (แสดงในบรรทัดเดียวกัน) เหมาะสำหรับการจัดวางองค์ประกอบที่ต้องการให้แสดงในบรรทัดเดียวกัน
  • inline-block - องค์ประกอบจะแสดงเป็นอินไลน์บล็อก (แสดงในบรรทัดเดียวกันแต่สามารถกำหนดขนาดได้) เหมาะสำหรับ ปุ่ม
  • flex - องค์ประกอบจะแสดงเป็น flex container เหมาะสำหรับการจัดวางองค์ประกอบในแนวตั้งหรือแนวนอน
  • grid - องค์ประกอบจะแสดงเป็น grid container เหมาะสำหรับการจัดวางองค์ประกอบในตาราง
  • none - องค์ประกอบจะไม่แสดง

Flexbox

Flexbox คือระบบการจัดวางองค์ประกอบในแนวตั้งหรือแนวนอนที่มีความยืดหยุ่นสูง

  • flex-direction - กำหนดทิศทางของ flex items
    1. row - จัดวาง flex items ตามแนวนอนจากซ้ายไปขวา
    2. column - จัดวาง flex items ตามแนวตั้งจากบนลงล่าง
    3. row-reverse - จัดวาง flex items ตามแนวนอนจากขวาไปซ้าย
    4. column-reverse - จัดวาง flex items ตามแนวตั้งจากล่างขึ้นบน
  • justify-content - กำหนดการจัดวาง flex items ในแนวนอน
    1. flex-start - จัดวาง flex items ที่ขอบซ้ายของ container
    2. flex-end - จัดวาง flex items ที่ขอบขวาของ container
    3. center - จัดวาง flex items ตรงกลางของ container
    4. space-between - จัดวาง flex items ให้มีช่องว่างเท่ากันระหว่างกัน
    5. space-around - จัดวาง flex items ให้มีช่องว่างเท่ากันรอบๆ กัน
  • align-items - กำหนดการจัดวาง flex items ในแนวตั้ง
    1. flex-start - จัดวาง flex items ที่ขอบบนของ container
    2. flex-end - จัดวาง flex items ที่ขอบล่างของ container
    3. center - จัดวาง flex items ตรงกลางของ container
    4. baseline - จัดวาง flex items ตามบรรทัดพื้นฐานของ container
    5. stretch - ขยาย flex items เพื่อเต็มพื้นที่ของ container
  • flex-wrap - กำหนดว่าควรให้ flex items ห่อหรือไม่
    1. nowrap - ไม่ให้ flex items ห่อ
    2. wrap - ให้ flex items ห่อลงบรรทัดใหม่
    3. wrap-reverse - ให้ flex items ห่อขึ้นบรรทัดใหม่
  • align-content - กำหนดการจัดวาง flex lines เมื่อมีหลายบรรทัด
    1. flex-start - จัดวาง flex lines ที่ขอบบนของ container
    2. flex-end - จัดวาง flex lines ที่ขอบล่างของ container
    3. center - จัดวาง flex lines ตรงกลางของ container
    4. space-between - จัดวาง flex lines ให้มีช่องว่างเท่ากันระหว่างกัน
    5. space-around - จัดวาง flex lines ให้มีช่องว่างเท่ากันรอบๆ กัน

Grid Layout

Grid Layout คือระบบการจัดวางองค์ประกอบในรูปแบบตารางที่มีความยืดหยุ่นสูง

  • grid-template-columns - กำหนดจำนวนและขนาดของคอลัมน์ใน grid
    •             .container {
                display: grid;
                grid-template-columns: 100px 200px 1fr;
            }
  • grid-template-rows - กำหนดจำนวนและขนาดของแถวใน grid
    •             .container {
                display: grid;
                grid-template-rows: 100px 200px 1fr;
            }
  • grid-gap - กำหนดช่องว่างระหว่างคอลัมน์และแถวใน grid
    •             .container {
                display: grid;
                grid-gap: 10px;
            }
  • grid-template-areas - กำหนดพื้นที่ของ grid โดยใช้ชื่อพื้นที่
    •             .container {
                display: grid;
                grid-template-areas:
                    "header header header"
                    "sidebar content content"
                    "footer footer footer";
            }

Responsive Design

Responsive Design คือการออกแบบเว็บไซต์ให้สามารถแสดงผลได้ดีบนอุปกรณ์ที่มีขนาดหน้าจอแตกต่างกัน

  • Media Queries - ใช้ในการกำหนดสไตล์ที่แตกต่างกันสำหรับอุปกรณ์ที่มีขนาดหน้าจอแตกต่างกัน
    •             @media (max-width: 600px) {
                .container {
                    display: block;
                }
            }
  • Flexible Layouts - ใช้การจัดวางที่ยืดหยุ่นเพื่อให้เว็บไซต์สามารถปรับตัวได้ตามขนาดหน้าจอ
    •             .container {
                display: flex;
                flex-wrap: wrap;
            }
  • Responsive Images - ใช้ภาพที่สามารถปรับขนาดได้ตามขนาดหน้าจอ
    •             img {
                max-width: 100%;
                height: auto;
            }
