Comment tag

Comment tag ใช้สำหรับใส่คำอธิบายหรือบันทึกในโค้ด HTML ซึ่งจะไม่แสดงผลบนหน้าเว็บ

รูปแบบการเขียน Comment tag:

<!-- นี่คือคำอธิบายหรือบันทึก -->    (คีย์ลัด Ctrl + /)

ส่วนสำคัญที่ควรมีในเอกสาร HTML

  • <!DOCTYPE html>: ใช้เพื่อระบุว่าเอกสารนี้เป็นเอกสาร HTML5
  • <html lang="...">: ใช้เพื่อระบุภาษาหลักของเอกสาร HTML
  • <head>: ส่วนหัวของเอกสาร HTML ซึ่งใช้สำหรับใส่ข้อมูลเมตา เช่น ชื่อเรื่อง, การเชื่อมโยงไฟล์ CSS, สคริปต์ JavaScript เป็นต้น
  • <meta charset="UTF-8">: ใช้เพื่อกำหนดการเข้ารหัสตัวอักษรของเอกสาร HTML เป็น UTF-8 ซึ่งรองรับตัวอักษรหลากหลายภาษา
  • <meta name="viewport" content="width=device-width, initial-scale=1.0">: ใช้เพื่อควบคุมการแสดงผลบนอุปกรณ์เคลื่อนที่ โดยกำหนดความกว้างของ viewport ให้เท่ากับความกว้างของอุปกรณ์ และตั้งค่าเริ่มต้นของการซูมเป็น 1.0
  • <title>: ใช้เพื่อกำหนดชื่อเรื่องของหน้าเว็บ ซึ่งจะแสดงในแถบชื่อเรื่องของเบราว์เซอร์
  • <body>: ส่วนเนื้อหาหลักของเอกสาร HTML ซึ่งใช้สำหรับใส่เนื้อหาที่จะแสดงบนหน้าเว็บ เช่น ข้อความ, รูปภาพ, ลิงก์ เป็นต้น

การลิงก์ข้อมูล

การลิงก์ข้อมูลมีอยู่หลายประเภท เช่น ลิงก์ภายในเว็บไซต์เดียวกัน, ลิงก์ไปยังเว็บไซต์อื่น, ลิงก์ไปยังส่วนต่างๆ ของหน้าเว็บ เป็นต้น

ตัวอย่างการลิงก์แต่ละลิงก์

  • ลิงก์ภายในเว็บไซต์เดียวกัน: <a href="page2.html">ไปยังหน้าที่ 2</a>
  • ลิงก์ไปยังเว็บไซต์อื่น: <a href="https://www.example.com">ไปยัง Example.com</a>
    • <a href="http://www.google.com"></a>
  • ลิงก์ไปยังส่วนต่างๆ ของหน้าเว็บ: <a href="#section1">ไปยังส่วนที่ 1</a>
    • <a href="#Comment"></a>

ในกรณีที่ต้องลิงก์ไฟล์ในโฟรเดอร์อื่น

ถ้าไฟล์ที่ต้องการลิงก์อยู่ในโฟรเดอร์อื่น ต้องระบุเส้นทางสัมพัทธ์ (relative path) หรือเส้นทางสัมบูรณ์ (absolute path)

  • เส้นทางสัมพัทธ์ (relative path): <a href="../folder/page.html">ไปยังหน้าในโฟรเดอร์อื่น</a>
  • เส้นทางสัมบูรณ์ (absolute path): <a href="https://www.example.com/folder/page.html">ไปยังหน้าในเว็บไซต์อื่น</a>

และอีกกรณีนึงถ้าขี้เกียจเลื่อนสกอร์เมาส์

สามารถสร้างลิงก์กลับไปยังด้านบนของหน้าเว็บได้ด้วยการใช้แท็ก <a> ร่วมกับแอตทริบิวต์ href ที่ชี้ไปยัง id ขององค์ประกอบที่อยู่ด้านบนสุดของหน้า

ตัวอย่าง: <a href="#top">กลับไปด้านบน</a>

การแสดงสื่อมีเดียใน HTML

HTML รองรับการแสดงสื่อมีเดียต่างๆ เช่น รูปภาพ, วิดีโอ, และเสียง โดยใช้แท็กต่างๆ เช่น <img>, <video>, และ <audio>

ตัวอย่างการแสดงรูปภาพ:

    <img src="autumn-950897_1280.jpg" alt="คำอธิบายรูปภาพ" width="150px" height="100px">

ตัวอย่างการแสดงเสียง:

    <audio controls>
        <source src="LIELIFE ： เกลียดตัวเอง ( Hate myself ).mp3" type="audio/mpeg">
    </audio>

ตัวอย่างการแสดงวิดีโอ:

    <video width="150px" height="auto" controls>
        <source src="Download.mp4" type="video/mp4">
    </video>

โครงสร้างตารางใน HTML

ตารางใน HTML ใช้แท็ก <table> เพื่อสร้างตาราง และใช้แท็ก <tr> เพื่อสร้างแถว, <th> เพื่อสร้างหัวข้อคอลัมน์, <td> เพื่อสร้างเซลล์ข้อมูล, <thead> เพื่อสร้างส่วนหัวของตาราง, <tbody> เพื่อสร้างส่วนเนื้อหาของตาราง และมีการรวมเซลล์ด้วย <colspan>ขยายแนวนอน และ <rowspan>ขยายแนวตั้ง

ตัวอย่างโครงสร้างตาราง:

th th
td td
colspan
rowspan td
td

การสร้างแบบฟอร์มใน HTML

แบบฟอร์มใน HTML ใช้แท็ก <form> เพื่อสร้างแบบฟอร์ม และใช้แท็กต่างๆ เช่น <input>, <textarea>, <select>, <option>, <label> เพื่อสร้างองค์ประกอบต่างๆ ในแบบฟอร์ม และมีคีย์สำคัญ:required จะทำให้ฟิลด์นั้นเป็นฟิลด์ที่บังคับกรอก

HTML Entity

HTML Entity (เอนทิตี HTML) คือ รหัสพิเศษที่ใช้แทนตัวอักษรหรือสัญลักษณ์ที่มีความหมายพิเศษใน HTML เพื่อป้องกันไม่ให้เบราว์เซอร์ตีความผิด ตัวอย่างเช่น การใช้ & แทนเครื่องหมาย < หรือ > แทนเครื่องหมาย > เป็นต้น

ตัวอย่าง HTML Entity ที่ใช้บ่อย:

  • &nbsp; : ช่องว่าง (non-breaking space)
  • &lt; : เครื่องหมาย < (less than)
  • &gt; : เครื่องหมาย > (greater than)
  • &amp; : เครื่องหมาย & (ampersand)
  • &quot; : เครื่องหมาย " (double quote)
  • &apos; : เครื่องหมาย ' (single quote)
  • &copy; : สัญลักษณ์ลิขสิทธิ์ (©)
  • &reg; : สัญลักษณ์เครื่องหมายการค้า (®)
  • &euro; : สัญลักษณ์ยูโร (€)
  • &pound; : สัญลักษณ์ปอนด์ (£)
  • &yen; : สัญลักษณ์เยน (¥)
  • &cent; : สัญลักษณ์เซ็นต์ (¢)
  • &sect; : สัญลักษณ์มาตรา (§)
  • &para; : สัญลักษณ์ย่อหน้าหรือพารากราฟ (¶)
  • &bull; : สัญลักษณ์หัวข้อย่อย (•)
  • &hellip; : สัญลักษณ์จุดไข่ปลา (…)
  • &mdash; : สัญลักษณ์ขีดยาว (—)
  • &ndash; : สัญลักษณ์ขีดกลาง (–)
  • &trade; : สัญลักษณ์เครื่องหมายการค้า (™)
