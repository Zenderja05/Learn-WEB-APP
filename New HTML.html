HTML

คืออะไร

  • HTML ไม่ใช่ภาษาโปรแกรม
  • แต่เป็น ภาษากำหนดโครงสร้างเอกสารของเว็บ

โครงสร้างมาตรฐาน

            <!DOCTYPE html>
            <html lang="en">
            <head>
                <meta charset="UTF-8">
                <meta name="viewport" content="width=device-width, initial-scale=1.0">
                <title>Document</title>
            </head>
            <body>
        
                <h1>hello world</h1>
                <p>This is website</p>

            </body>
            </html>

อธิบายแต่ละส่วน

ส่วน หน้าที่
<!DOCTYPE html> บอกเบราว์เซอร์ว่าเป็น HTML5
<html lang="en"> ครอบทั้งหน้าเว็บ
<head> ข้อมูลเบื้องหลังเว็บ
<body> สิ่งที่ผู้ใช้เห็น

Tag / Element / Attribute

  • Tag

    • <แท็กเปิด> ข้อความ </แท็กปิด>
    <p> This is website </p>

  • Element

    • <p>This is website</p>

    ทั้งหมดเรียกว่า Element

  • Attribute

    • <a href="www.google.com">google</a>

    href = attribute

    "https://..." = ค่า

Tag พื้นฐาน

  • Tag หัวข้อ

    • h1(ใหญ่สุด)-h6(เล็กสุด)

  • Tag ข้อความ

    • <p> : สำหรับย่อหน้า

    <pre> : สำหรับข้อความที่มีการจัดเรียง

  • Tag link

    • ลิงก์ทั่วไป

    <a href="ชื่อไฟล์/ลิงก์เว็บ">ข้อความหน้าเว็บ</a>

    ลิงก์ไปอีกแท็บนึง

    <a href="ชื่อไฟล์/ลิงก์เว็บ" target="_blank">ข้อความหน้าเว็บ</a>

  • Tag รูปภาพ

    • <img src="ไฟล์รูปภาพ" alt="ชื่อรูปภาพ">

  • Tag list
    • รายการไม่มีลำดับ
      •             <ul>
                <li>ทีวี</li>
                <li>ปลั๊กไฟ</li>
                <li>ท่อ</li>
            </ul>
    • รายการมีลำดับ
      •             <ol>
                <li>1</li>
                <li>2</li>
                <li>3</li>
            </ol>
  • Tag table
    •                 <table>
                    <tr>
                        <th>หัวข้อ</th>
                    </tr>
                    <tr>
                        <td>เนื้อหา</td>
                    </tr>
                </table>
    แท็ก หน้าที่
    <table> ตาราง
    <tr> แถว
    <th> หัวตาราง/หัวข้อ
    <td> ข้อมูล
