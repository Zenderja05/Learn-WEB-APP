HTML

โครงสร้างพื้นฐานของ HTML

        <!DOCTYPE html>
        <html lang="en">
        <head>
            <meta charset="UTF-8">
            <meta name="viewport" content="width=device-width, initial-scale=1.0">
            <title>Document</title>
        </head>
        <body>
            
        </body>
        </html>
  • <!DOCTYPE html> - ประกาศชนิดของเอกสารว่าเป็น HTML5
  • <html> - ตัว container หลักของหน้าเว็บ
  • <head> - ข้อมูลที่ไม่แสดงในหน้าเว็บ เช่น title, meta tags
    • <meta charset="UTF-8"> - กำหนด encoding ของหน้าเว็บ
    • <meta name="viewport" content="width=device-width, initial-scale=1.0"> - ทำให้เว็บ Responsive
    • <title>Document</title> - กำหนดชื่อหน้าเว็บ
  • <body> - เนื้อหาที่แสดงในหน้าเว็บ

Semantic Structure Tag

Semantic Structure Tag คือแท็กที่มีความหมายเฉพาะเจาะจงในการจัดโครงสร้างของเนื้อหาในหน้าเว็บ ซึ่งช่วยให้เครื่องมือค้นหาและผู้ใช้เข้าใจเนื้อหาได้ดีขึ้น

  • <header> - ส่วนหัวของหน้าเว็บหรือส่วนของเนื้อหา
  • <nav> - ส่วนที่ใช้สำหรับการนำทาง
  • <main> - เนื้อหาหลักของหน้าเว็บ
  • <section> - ส่วนที่ใช้สำหรับแบ่งเนื้อหาเป็นส่วนๆ
  • <article> - เนื้อหาที่สามารถแยกออกมาเป็นหน่วยเดียวได้ เช่น บทความ
  • <aside> - เนื้อหาที่เกี่ยวข้องแต่ไม่ใช่ส่วนหลัก เช่น แถบด้านข้าง คล้ายป้ายโฆษณาตามเว็บ
  • <footer> - ส่วนท้ายของหน้าเว็บหรือส่วนของเนื้อหา

Text Tag

Text Tag คือแท็กที่ใช้สำหรับจัดรูปแบบข้อความในหน้าเว็บ

  • <h1> ถึง <h6> - แท็กหัวเรื่องที่มีระดับความสำคัญต่างกัน
  • <p> - แท็กย่อหน้า
  • <strong>,≪b> - แท็กเน้นข้อความให้เด่นชัด (ตัวหนา)
  • <em> - แท็กเน้นข้อความให้เด่นชัด (ตัวเอียง)
  • <br> - แท็กขึ้นบรรทัดใหม่
  • <hr> - แท็กเส้นแบ่งเนื้อหา

List Tag

List Tag คือแท็กที่ใช้สำหรับสร้างรายการในหน้าเว็บ

  • <ul> - แท็กลิสต์ที่ไม่มีลำดับ (unordered list)
  • <ol> - แท็กลิสต์ที่มีลำดับ (ordered list)
  • <li> - แท็กสำหรับรายการในลิสต์

Link Tag

Link Tag คือแท็กที่ใช้สำหรับสร้างลิงก์ในหน้าเว็บ

  • <a> - แท็กสำหรับสร้างลิงก์
  • href - แอตทริบิวต์ที่ใช้กำหนด URL ของลิงก์
  • target - แอตทริบิวต์ที่ใช้กำหนดวิธีการเปิดลิงก์ เช่น _blank เปิดในแท็บใหม่

Media Tag

Media Tag คือแท็กที่ใช้สำหรับแทรกสื่อในหน้าเว็บ เช่น รูปภาพ วิดีโอ หรือเสียง

  • <img> - แท็กสำหรับแทรกรูปภาพ
    • src - แอตทริบิวต์ที่ใช้กำหนด URL ของรูปภาพ
    • alt - แอตทริบิวต์ที่ใช้กำหนดข้อความสำรองเมื่อรูปภาพไม่สามารถโหลดได้
                <img src="image.jpg" alt="คำอธิบายรูปภาพ">
  • <video> - แท็กสำหรับแทรกวิดีโอ
    •             <video controls>
            <source src="video.mp4" type="video/mp4">
            <source src="video.ogg" type="video/ogg">
  • <audio> - แท็กสำหรับแทรกเสียง
    •             <audio controls>
            <source src="audio.mp3" type="audio/mpeg">
            <source src="audio.ogg" type="audio/ogg">

Table Tag

Table Tag คือแท็กที่ใช้สำหรับสร้างตารางในหน้าเว็บ

  • <table> - แท็กสำหรับสร้างตาราง
  • <tr> - แท็กสำหรับสร้างแถวในตาราง
  • <th> - แท็กสำหรับสร้างเซลล์หัวเรื่องในตาราง
  • <td> - แท็กสำหรับสร้างเซลล์ข้อมูลในตาราง
        <table>
            <tr>
                <th>หัวเรื่อง 1</th>
                <th>หัวเรื่อง 2</th>
            </tr>
            <tr>
                <td>ข้อมูล 1</td>
                <td>ข้อมูล 2</td>
            </tr>
        </table>

Form Tag

Form Tag คือแท็กที่ใช้สำหรับสร้างแบบฟอร์มในหน้าเว็บ เพื่อให้ผู้ใช้สามารถกรอกข้อมูลและส่งไปยังเซิร์ฟเวอร์ได้

  • <form> - แท็กสำหรับสร้างแบบฟอร์ม
  • action - แอตทริบิวต์ที่ใช้กำหนด URL ที่จะส่งข้อมูลไปเมื่อแบบฟอร์มถูกส่ง
  • method - แอตทริบิวต์ที่ใช้กำหนดวิธีการส่งข้อมูล เช่น GET หรือ POST
  • <input> - แท็กสำหรับสร้างช่องกรอกข้อมูล
    • type - แอตทริบิวต์ที่ใช้กำหนดประเภทของช่องกรอกข้อมูล เช่น text, password, email, submit เป็นต้น
    • name - แอตทริบิวต์ที่ใช้กำหนดชื่อของช่องกรอกข้อมูล เพื่อให้เซิร์ฟเวอร์สามารถรับข้อมูลได้
        <form action="/submit" method="post">
            <input type="text" name="username">
            <input type="password" name="password">
            <input type="submit" value="Submit">
        </form>

GET & POST

GET และ POST คือวิธีการส่งข้อมูลจากหน้าเว็บไปยังเซิร์ฟเวอร์

  • GET - ใช้ส่งข้อมูลผ่าน URL ซึ่งข้อมูลจะปรากฏใน URL ของหน้าเว็บ

    • ใช้เมื่อ

    1. ต้องการส่งข้อมูลที่ไม่สำคัญหรือไม่เป็นความลับ เช่น การค้นหา
    2. ต้องการให้ข้อมูลสามารถแชร์ได้ผ่าน URL
    3. ต้องการให้ข้อมูลถูกเก็บในประวัติการเข้าชมของเบราว์เซอร์
  • POST - ใช้ส่งข้อมูลผ่าน body ของ HTTP request ซึ่งข้อมูลจะไม่ปรากฏใน URL

    • ใช้เมื่อ

    1. ต้องการส่งข้อมูลที่สำคัญหรือเป็นความลับ เช่น รหัสผ่าน
    2. ต้องการส่งข้อมูลที่มีขนาดใหญ่ เช่น ไฟล์
    3. ไม่ต้องการให้ข้อมูลถูกเก็บในประวัติการเข้าชมของเบราว์เซอร์

Attribute

Attribute คือแอตทริบิวต์ที่ใช้เพื่อระบุคุณสมบัติของแท็ก HTML

  • class - ใช้กำหนดชื่อคลาสของแท็ก เพื่อใช้กับ CSS หรือ JavaScript
  • id - ใช้กำหนด ID ของแท็ก เพื่อใช้กับ CSS หรือ JavaScript
  • style - ใช้กำหนดสไตล์ของแท็กโดยตรง
  • alt - ใช้กำหนดข้อความแสดงแทนภาพหากภาพไม่สามารถแสดงได้
  • href - ใช้กำหนด URL ของลิงก์
  • src - ใช้กำหนด URL ของสื่อ เช่น รูปภาพ วิดีโอ หรือเสียง
  • type - ใช้กำหนดประเภทของสื่อ เช่น image/jpeg, video/mp4, audio/mpeg
  • action - ใช้กำหนด URL ที่จะส่งข้อมูลไปเมื่อแบบฟอร์มถูกส่ง
  • method - ใช้กำหนดวิธีการส่งข้อมูล เช่น GET หรือ POST
